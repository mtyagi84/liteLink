Laptop Handoff Plan

A record of everything Claude Code keeps outside your project repos — memory, chat history, skills, and settings — plus the exact steps to move it to a new machine without losing any of it.

MAP What lives where

Project code is already safe in git. Everything below is the part that isn't — it lives only in your Windows user profile.

WhatLocationContains
Chat history ~\.claude\projects\ Full transcript of every session, grouped per project folder
Auto-memory ~\.claude\projects\<project>\memory\ MEMORY.md index + individual memory files, per project
Global settings ~\.claude\settings.json Permissions, hooks, model preferences
Plugins & skills ~\.claude\plugins\ Marketplaces, installed plugin list, plugin data — superpowers, apex, remember
Login ~\.claude\.credentials.json Claude account token
Keybindings ~\.claude\keybindings.json Custom key rebinds, if any are set
Project code C:\Manglu\VMS\, C:\Manglu\VMS\ZYX\ Already in git — VMS repo, ZYX/liteLink repo. Safe as long as it's pushed.

01 Set up today, before you need it

These three take five minutes now and prevent a bad week later.

ActionPriorityWhy
Back up the .claude folder critical Not tracked in git anywhere — the only copy of memory, history, and skills
Confirm every project has a pushed remote critical Anything unpushed exists only on this laptop
Put the backup on a schedule recommended Weekly, so it's never more than a few days stale 
robocopy "C:\Users\<user>\.claude" "D:\Backup\claude-backup" /MIR /XD cache downloads shell-snapshots
Excludes cache, downloads, shell-snapshots — disposable, regenerated automatically. Point the destination at OneDrive, an external drive, or a private git repo.

02 On the new laptop

Run in order — path 5 is the one step that silently breaks memory if skipped.

StepNotes
Install Claude Code —
Log in A fresh login is cleaner than restoring .credentials.json, but either works
Copy the backed-up .claude folder into place Target: C:\Users\<newuser>\.claude
Clone each project repo VMS, liteLink/ZYX, etc.
Keep the same drive letter and folder paths Memory is keyed by folder path — c--Manglu-VMS-ZYX comes from C:\Manglu\VMS\ZYX. Match paths and memory resolves with no manual edits.
Open a session per project and verify memory loaded Ask: "what do you remember about this project?"

— What a perfect backup still won't save

RiskMitigation
In-flight, unsaved session state Let active sessions wrap up before copying — don't migrate mid-session
Credentials stored outside .claude Check Windows Credential Manager for any tool-specific tokens
